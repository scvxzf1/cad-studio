# 结构件紧固件、常用接口与 FDM/CNC 双模公差速查手册

本手册帮助 Agent 将用户的**中文机械/打印行话**直接映射为准确的工程结构与 `cad_kit` API，无需每次向用户追问标准件尺寸。

---

## 一、 口语行话 → `cad_kit` 标准特征映射表

| 用户常见说法 | 机械含义 | 推荐 `cad_kit` 调用方式 | 设计要点 |
| :--- | :--- | :--- | :--- |
| **“M3 通孔 / 过孔”** | 螺丝直接穿过的无螺纹光孔 | `make_hole_cutter(tol, "M3", depth, kind="clearance")` | `fdm` 下自动扩至 `3.55mm` 防缩孔；精定位孔用 `kind="close"` (`3.35mm`) |
| **“M3 自攻孔 / 攻丝底孔”** | 螺丝直接拧入塑料自攻，或 CNC 丝锥攻牙底孔 | `make_hole_cutter(tol, "M3", depth, kind="tap")` | `fdm` 自动给 `2.75mm` 塑料自攻孔；`cnc` 自动给 `2.50mm` 标准丝锥底孔 |
| **“M3 沉头孔 / 杯头孔 / 内六角沉孔”** | 圆柱头内六角螺丝（ISO 4762 / DIN 912）台阶沉孔 | `make_counterbore_cutter(tol, "M3", depth)` | 若在 FDM 悬空底面朝下打沉头孔，传 `upside_down_bridge=True` 自动留 `0.2mm` 单层吊桥免支撑！ |
| **“M3 平头孔 / 皿头孔 / 锥头沉孔”** | 90° 平头沉头螺丝（ISO 10642）锥孔 | `make_countersink_cutter(tol, "M3", depth)` | 薄板（壁厚 `< 3mm`）优先用皿头锥孔代替杯头沉孔 |
| **“M3 热熔螺母孔 / 滚花铜螺母”** | 电烙铁热压嵌入滚花黄铜螺母（如 M3×D4.5×L5） | `make_heatset_cutter(tol, "M3", screw_relief_depth=3.0)` | 自带 `0.8mm` 深顶部导向定心台阶 + 底部溢胶与螺丝余量孔；周边柱子壁厚至少 `≥ 2.0mm`（推荐柱外径 `Ø8.5~9.0mm`） |
| **“M3 螺母槽 / 嵌螺母 / 侧面塞螺母”** | 防转六角螺母槽（顶入式或侧面滑入式） | `make_nut_trap_cutter(tol, "M3", side_slot_len=...)` | 垂直锁紧支架常用 `side_slot_len=12.0` 生成侧面横向滑入式防掉螺母方槽 |
| **“腰型孔 / 长圆孔 / 条形调节孔”** | 允许安装位置微调的跑道形槽孔 | `make_slot_cutter(tol, "M3", center_span=8.0, depth=...)` | 默认沿 X 轴延展；沿 Y 轴加 `Rot(0, 0, 90)` |
| **“加强筋 / 三角筋 / 肋板”** | 直角连接处防弯折三角支撑板 | `make_rib(length, height, thickness=2.4)` | 筋厚一般取主壁厚的 `0.6~0.8` 倍（FDM 常用 `2.0~3.0mm`） |
| **“螺丝柱 / 铜柱凸台 / 支撑柱”** | PCB 或外壳内部立柱 | `make_mounting_boss(outer_d=8.5, height=10.0)` | 默认自带底部锥形防断根部加强过渡 |

## 三、 常见电子/机电标准接口速查（缺省参考）

1. **常见轴承外径 × 内径 × 厚 (`mm`)**：
   - `608` 轴承：`Ø22.0 × Ø8.0 × 7.0`（FDM 轴承外圈压入孔建议留 `tol.clearance("press")` 每侧 `+0.05mm`，即 `Ø22.1mm`）
   - `625` 轴承：`Ø16.0 × Ø5.0 × 5.0`
   - `MR85` 轴承：`Ø8.0 × Ø5.0 × 2.5`
   - `F695` 法兰轴承：`Ø13.0 (法兰 Ø15.0) × Ø5.0 × 4.0`
2. **步进电机安装尺寸 (`mm`)**：
   - **NEMA 17**（42 步进电机）：外框 `42.3 × 42.3`，四角孔距 **`31.0 × 31.0`**（M3 螺丝），中心止口凸台 **`Ø22.0 × 高 2.0`**（面板中心孔取 `Ø22.5`）。
   - **NEMA 14**（35 步进电机）：外框 `35.2 × 35.2`，四角孔距 **`26.0 × 26.0`**（M3），中心止口 **`Ø22.0`**。
3. **常用接口面板开孔 (`mm`，未含额外间隙，开孔时加 `2 * tol.clearance("snug")`)**：
   - **USB Type-C 母座开孔**：圆角矩形约 `9.2 × 3.4`（R1.6），带插头塑料壳避让沉槽建议 `12.6 × 6.8`。
   - **DC-005 电源圆孔 / 螺纹面板孔**：常见 `Ø8.0` 或 `Ø11.0`。
4. **3D 打印结构经验准则（DFM）**：
   - **底边贴热床用倒角不用圆角**：贴 `Z=0` 热床的底边圆角会产生近水平悬垂导致边缘起翘粗糙，一律用 `45°` 倒角（`tol.bed_chamfer`）。
   - **外壳上下盖止口（Lip & Groove）**：壁厚建议 `≥ 2.4mm`；止口高度 `1.6~2.0mm`，内外侧单边配合间隙取 `tol.clearance("snug")`（FDM 下每侧 `0.12~0.15mm`）。
   - **悬臂卡扣（Snap-Fit）**：根部必须加圆角防应力集中断裂，尽可能让卡扣弯曲方向位于 XY 层内（沿层纹方向抗拉不断裂，Z 向层间易劈裂）。
